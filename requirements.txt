# Every dependency here is pinned with `==`. Nothing uses `>=`.
#
# On 2026-08-21 `anthropic>=0.40.0` resolved to 1.0.0 on a routine rebuild.
# 1.0.0 moved `temperature` out of `AsyncMessages.stream()`, so every turn
# raised TypeError and every reply degraded to the safe fallback phrase. All
# four clinic services went down mid-morning without one line of our code
# changing, and a revert did not fix it — the range re-resolved on the next
# build. Tests cannot catch this: CI installs the same floating range.
#
# The remaining seven ranges were pinned on 2026-08-25 to the versions the
# Render build was ALREADY resolving (`pip freeze` on the running service), so
# the pin froze the live set rather than moving it. Worth noting what the
# ranges had quietly floated to: `openai>=1.50.0` was serving 3.3.1 — two major
# versions — and `pytest-asyncio>=0.23.0` was on 1.4.0.
#
# To change a version: change it here deliberately, deploy, and make a real
# call. Never widen a pin back to a range.
